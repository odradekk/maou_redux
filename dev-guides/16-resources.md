本章介绍EraElectron引擎对图片和音乐等多媒体资源的支持，涉及资源文件在引擎中的注册和7个相关 API。要想使用多媒体资源，必须在引擎的游戏设置中把 [启用资源](./03-config#systemresource是否启用资源) 选项打开，否则引擎不会读取资源文件，也不会显示或播放。

所有多媒体资源都需要放置在游戏文件夹下的 res 文件夹下，需和其他文件夹满足以下的文件结构：

    游戏文件夹
    ├── csv（或其他静态数据文件夹）
    ├── ere（游戏脚本集）
    └── res（多媒体资源文件夹）

# 图片资源

EraElectron引擎支持两种风格的图片显示：切分图和全图。

* 切分图是 emuera 支持的图片处理风格，多张图片可以粘贴在同一张图片中，引擎每次显示时只会取用其中的一部分，因此显示出的图片尺寸是固定的。
* 全图模式是EraElectron引擎专属的显示风格，每次显示都会将整张图片显示出来，但同时这样的图片可以随着所处网格的尺寸自适应缩放。

两种风格的图片文件都需要通过处于 **同文件夹** 的 csv 文件注册，然后才可以在引擎中使用。res 文件夹中可以有多级多层子文件夹，但每个文件夹中的 csv 文件只能注册同文件夹中的图片文件，也就是说必须满足如下的文件结构：

    res
    ├── sub-res-1
    │   ├── sub-sub-res
    │   │   ├── 图片A.png
    │   │   ├── 图片B.png
    │   │   └── 1.csv（注册了图片A和图片B）
    │   ├── 图片C.png
    │   ├── 图片D.png
    │   └── 2.csv（注册了图片C和图片D）
    ├── sub-res-2
    │   ├── 图片E.png
    │   ├── 图片F.png
    │   └── 3.csv（注册了图片E和图片F）
    ├── 图片G.png
    ├── 图片H.png
    └── 4.csv（注册了图片G和图片H）

本节中会使用 [eratohoYMAEM](https://gitgud.io/era-games-zh/touhou/eratohoYMAEM_Chinese) 中的图片资源作为例子来介绍图片资源的注册和使用方式。

## 注册

EraElectron引擎支持以下几种常见图片格式：.gif、.jpeg、.jpg、.png、.svg 和 .webp。注册用的 csv 文件格式如下所示：

```csv
; 完整的切分图注册方式
注册名,图片文件名,图片起始横坐标,图片起始纵坐标,图片宽度,图片高度,图片显示横坐标,图片显示纵坐标

; 省略的切分图注册方式
注册名,图片文件名,图片起始横坐标,图片起始纵坐标,图片宽度,图片高度
; 这种方式下图片显示的横纵坐标都会取0

; 完整的全图注册方式
注册名,图片文件名,0,0,图片宽度,图片高度

; 省略的全图注册方式
注册名,图片文件名
; 这种方式下图片宽度和图片高度会自动读取
```

以上使用的横纵坐标和宽高的单位都是px（像素）。

**注册用 csv 文件中的图片文件必须和该 csv 文件处于同一文件夹下！**

在注册完成之后，游戏中就可以使用这些图片的注册名进行显示了。

### 切分图

切分图注册方式中的各项参数综合来讲，就是在显示图片时，从图片文件的起始横纵坐标开始，取相应宽度和高度的区域，然后显示在图片显示横纵坐标开始的地方。

显示切分图需要使用 API [era.printImage](#eraprintimage)。

### 全图

全图使用时每次都会显示整张图片，所以不需要在注册时指明各种偏移量和横纵坐标，至多只需要标注图片的宽度和高度。在省略的注册方式下，甚至连宽度和高度也不需要标注。EraElectron引擎引入了 [image-size](https://www.npmjs.com/package/image-size) 库，在省略注册方式下会自动读取图片的宽度和高度。

显示全图需要使用 API [era.printWholeImage](#eraprintwholeimage)。

注意全图风格下最终使用的是 **整个图片文件**，在上面的例子中注册名 `'立ち絵_服_通常_1001'` 和 `'立ち絵_裸_笑い_1001'` 都对应文件 1001.png，因此以这两个注册名显示全图时会产生相同的效果：显示 1001.png 整张图片。

### 网络图片

可以在 csv 文件中注册网络图片，只需要将注册文件中的图片文件名换成图片的网址即可。但将网络图片注册为全图时必须使用完整的注册方式，因为库 image-size 无法读取网络图片的宽度和高度。

## 相关 API

### era.printImage

![era.printImage](../imgs/99-era.printImage.png)

用于显示切分图的 API，接受 String 类型的可变参数 names，其中是图片资源的注册名。

era.printImage 显示的切分图将严格遵循注册时填写的图片尺寸，并不会随窗口或网格大小变化而变化。例如下面的例子将输出一张尺寸恒定为180x180（px）的灵梦立绘：

```javascript
// #/main.js
// ...
era.printImage('立ち絵_服_通常_1001');
// ...
```

![灵梦](../imgs/99.2-灵梦.png)

在输入多个参数的情况下，图片会按照从下到上的顺序进行堆叠：

```javascript
// #/main.js
// ...
era.printImage(
  'CN17_发_後发_侧马尾',
  'CN16_他_後发_侧马尾',
  'CN15_肌_身体_和服1',
  'CN13_無_身体_和服1',
  'CN12_服_身体_和服1',
  'CN10_发_装飾_もみあげ普通(发)',
  'CN09_肌_頭部_普通な顔1',
  'CN08_发_装飾_もみあげ普通(发)',
  'CN07_無_表情_照れ(口閉じ)',
  'CN06_发_前发_お嬢様',
  'CN04_無_表情_三角口(困り)',
  'CN01_瞳_目瞳_だる目(黑め)1',
);
// ...
```

![叠图](../imgs/99.3-叠图.png)

注意先输入的参数对应的图片会显示在底部，最后输入的参数对应的图片则显示在顶部。

如果不确定图片是否存在，可以在同一个字符串中输入多个图片的注册名并以制表符（`\t`，按一下 Tab 键）分割，EraElectron引擎在处理该层的图片时会自动将其切分，并取第一个可以找到对应图片文件的注册名显示，例如下面的例子将只会显示笑颜的着服灵梦：

```javascript
// #/main.js
// ...
era.printImage('立ち絵_服_通常_1002\t立ち絵_服_笑い_1001\t立ち絵_裸_怒り_1001');
// ...
```

![容错](../imgs/99.4-容错.png)

在执行上面的语句时，EraElectron引擎首先检查`'立ち絵_服_通常_1002'`这个注册名，因为没有注册对应的图片文件，所以继续检查`'立ち絵_服_笑い_1001'`，发现有对应的图片文件，于是直接显示出来，不会再继续检查`'立ち絵_裸_怒り_1001'`。

另外，如果某些层的所有注册名都没有找到对应的图片文件，引擎会跳过这一层，即在这一层不输出任何图片。

### era.printWholeImage

![era.printWholeImage](../imgs/100-era.printWholeImage.png)

用于显示全图的 API，总是将注册的图片文件填充在窗口或网格中完整显示出来，且显示大小可随窗口或网格大小变化而变化：

```javascript
// #/main.js
// ...
era.printWholeImage('立ち絵_服_通常_1001');
// 全图显示的是整张图片，因此下面的代码会产生和上面的代码一样的效果
// era.printWholeImage('立ち絵_裸_笑い_1001');
// ...
```

![全图](../imgs/100.3-全图.png)

参数 names 为 String 或 String 数组类型，作用与 [era.printImage](#eraprintimage) 的参数 names 类似，都接受注册名。在传入单个字符串时，显示该注册名对应的图片；在传入多个字符串组成的数组时，显示这些注册名对应图片的叠加，顺序也是先传入的在底部，后传入的在顶部。

注册名也可以用 `\t` 连接，引擎会按顺序检查并显示第一个注册了的图片文件。

![WholeImageConfig](../imgs/100.2-WholeImageConfig.png)

config 参数为可选的对象类型的参数，可以有以下可选属性：

* fit：String 类型，图片在网格中的填充方式，有 `'fill'|'contain'|'cover'|'none'|'scale-down'` 五种取值，分别对应拉伸、缩放、裁切、保留原值、缩放或保留原值中更小的尺寸，默认值为 `'contain'`；
* offset：offset：Number 类型，该图片所在网格的偏移量；
* width：Number 类型，该图片所在网格的宽度。

### era.checkImage

![era.checkImage](../imgs/101-era.checkImage.png)

用于检查注册名对应图片是否存在的 API。当传入一个注册名时，返回 Boolean 类型，表示该注册名对应图片是否存在；传入多个注册名时，返回 Boolean 数组，与注册名一一对应，即：

```javascript
era.checkImage('图片A', '图片B', '图片C');
// 等价于
[era.checkImage('图片A'), era.checkImage('图片B'), era.checkImage('图片C')];
```

### era.setMask

![era.setMask](../imgs/102-era.setMask.png)

用于设置覆盖整个屏幕的滤镜的 API，调用后会将整张图片在界面上覆盖显示。玩家依然可以穿过该图片点击后续显示的文字或按钮。

era.setMask 接受两个可选参数：

* maskName：String 类型，要作为滤镜显示的图片文件注册名；
* opacity：Number 类型，0-1，滤镜的不透明度，0是完全透明，1是完全不透明。

当不带任何参数调用 era.setMask 时，会取消滤镜的显示。

例如：

```javascript
// #/main.js
// ...
era.setMask('立ち絵_服_通常_1001');
era.print('测试');
await era.waitAnyKey();
era.setMask();
// ...
```

在引擎中点击任意键之前会显示以下效果（在输入任意键之后滤镜消失）：

![滤镜](../imgs/102.1-滤镜.png)

### （进阶）全图模式的复杂用法

era.printWholeImage 和 WholeImageObject 中属性 names 作为数组时其中的元素也可以是对象，此时该元素对应的该图层的图片由对象中的 names 属性（String 类型）指定，该对象还可以带有其他一些属性以对图片进行调整。该对象的具体属性如下：

* names
  * **类型**：String 类型。
  * **描述**：该层图片的注册名。
  * **默认值**：必选属性，无默认值。
* [background（可选）](https://developer.mozilla.org/zh-CN/docs/Web/CSS/background)
  * **类型**：String 类型。
  * **描述**：该层图片的背景相关样式，如背景色等（注意EraElectron引擎中无法为图片设置背景图片）。
  * **默认值**：`''`
* [borderRadius（可选）](https://developer.mozilla.org/zh-CN/docs/Web/CSS/border-radius)
  * **类型**：Number 类型。
  * **描述**：该层图片边框圆角效果的程度，单位为px（像素）。
  * **默认值**：0
* [filter（可选）](https://developer.mozilla.org/zh-CN/docs/Web/CSS/filter)
  * **类型**：String 类型。
  * **描述**：该层图片的图片效果，如模糊、亮度调整、对比度调整、色相旋转（EraUma中路人调教立绘的发色毛色等变化就利用了色相旋转）等。
  * **默认值**：`''`

## （进阶）游戏图标

要为游戏设置图标，需要在 [GameBase.csv](./09-static#gamebasecsv) 中设置[游戏图标]变量，但不需要通过注册用 csv 文件在游戏中注册。游戏图标文件必须是最大 512x512 尺寸的 png 文件，[游戏图标]变量的取值必须是该文件相对于游戏文件夹的相对路径，例如如果游戏图标文件 icon.png 在 res 文件夹下，则[游戏图标]变量的取值就是 `res/icon.png`。

在任意格式的 GameBase 文件中注册后，游戏图标将在游戏加载时自动启用并替换引擎程序的图标，不会受游戏设置中 [启用资源] 选项的影响。

# 音乐资源

## 注册

EraElectron引擎支持以下几种常见音乐格式：.flac、.mp3、.wav 和 .wma。

和图片资源类似，音乐资源也需要在注册后使用。音乐资源的注册方式和省略的全图注册方式相同：

```csv
; res/注册.csv
; ...
注册名,音乐文件名
```

将音乐文件名换成音乐的网址即可注册网络音乐。

注册的音乐资源也可以利用 era.checkImage 检查注册名对应的音乐文件是否存在。

## 相关 API

### era.playMusic

![era.playMusic](../imgs/103-era.playMusic.png)

用于播放音乐的 API，有一个必选参数 names 和可选参数 config。

参数 names 类型为 String 或 String 数组，即一个或多个注册名，但是引擎只会播放第一个注册了的音乐文件。

config 参数为可选的对象类型的参数，可以有以下可选属性：

* loop：Boolean 类型，该音乐是否循环播放；
* fade：Boolean 类型，该音乐是否要与前面的音乐形成淡入淡出；
* fadeInternal：Number 类型，和 fade 配合使用，淡入淡出的时间间隔，单位为ms（毫秒），100-500，默认值为200（ms）。

### era.stopMusic

![era.stopMusic](../imgs/104-era.stopMusic.png)

用于停止音乐的 API。

### era.resumeMusic

![era.resumeMusic](../imgs/105-era.resumeMusic.png)

用于继续播放音乐的 API。如果在调用 era.stopMusic 时音乐未播放完，则调用 era.resumeMusic 会从停止的地方继续，否则从头开始播放音乐。

# 小结

本章介绍了图片和音乐等多媒体资源在EraElectron引擎中的使用方法。所有图片和音乐都需要先由同级文件夹下的 csv 文件进行注册，才能在引擎中通过注册名加以使用。

图片有两种使用风格，切分图风格会以固定大小显示原始图片的一部分，全图风格则会固定显示整张原始图片但大小可以随窗口/网格大小变化而变化。两种风格各有所长，注册方法也不尽相同，请读者按需使用。

EraElectron引擎支持注册网络图片或音乐，只需要在注册时将文件名换成对应网址即可，这种情况下注册全图时必须是完整的注册方式（即带有图片的宽度和高度）。可以通过 era.checkImage 来检查注册名对应的图片或音乐文件是否存在。
