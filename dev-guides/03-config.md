# 配置文件运行原理

1. 引擎会读取游戏文件夹下的ere.config.json并作为当前的游戏配置；
    1. 如果没有ere.config.json，引擎会从游戏文件夹下csv文件夹中的_config.json文件中读取默认配置；
    2. 如果没有\_config.json文件夹，也即游戏开发者没有指定默认配置，则引擎会新建一套默认的游戏配置；
2. 在读取或创建游戏配置后，引擎会尝试读取游戏文件夹/csv文件夹中的_fixed.json文件，然后将游戏配置中与\_fixed.json配置不同的内容强制改为_fixed.json中的内容，并锁定游戏配置界面中的相应配置选项
    * 例如_fixed.json中配置游戏窗口宽度为1,000px（像素），则无论ere.config.json、\_config.json、默认游戏配置中如何配置，都会强制修改窗口宽度为1,000px并不允许玩家自行修改。
3. 在完成上述操作后，引擎会将当前的游戏配置写回到游戏文件夹/ere.config.json中，供下次读取游戏时使用。

总结一下，配置项的作用优先级为：\_fixed.json > ere.config.json > \_config.json > 游戏引擎默认配置。

以上三种文件都是json格式的文件，且因为其中只会有任意字符编码都相同的基础字符，因此可以以任意编码保存。

# 可配置项具体作用

大部分配置项都可通过引擎菜单栏【帮助】-【游戏设置】控制，所有配置项可以表示为以下的json格式（其中的取值来自游戏引擎生成的默认配置）：

```json
{
  "system": {
    "_replace": false,
    "saveCompressedData": false,
    "resource": false,
    "saveFiles": 10,
    "collapseBlankLines": false,
    "hideUserInput": false,
    "disableClear": false,
    "extendedCharaTables": [],
    "static": "csv"
  },
  "window": {
    "width": 1000,
    "height": 880,
    "fontSize": 16,
    "audio": 100,
    "autoMax": false,
    "orientation": 1
  }
}
```

整个json文件定义了一个完整的对象，其中有名为system和window的两个成员对象，两个成员对象各有自己的成员变量。下文中笔者将使用x.y来形容json对象中x对象的y成员变量，例如`system._replace`指system成员对象中的_replace变量，`system.*`则表示system成员对象中的所有变量。

## system.\*：系统配置项

系统配置项主要用于控制游戏引擎系统的行为，包括存读档和启用资源等。

![系统配置项](../imgs/3-游戏设置-系统.png)

### system.\_replace：是否启用_Replace.csv

是否启用_Replace.csv中的定义来取代游戏的加载信息等，具体细节可见 [#9 静态数据文件](./09-static#_replacecsv)。

默认为禁用。

### system.saveCompressedData：是否压缩保存游戏存档

禁用时引擎会将存档保存为JSON格式的文件，启用时则会将存档数据以gzip压缩算法压缩后保存。

默认为禁用。

> 在安卓版引擎中恒为禁用。

### system.resource：是否启用资源

是否启用图片和音频等多媒体资源，禁用时游戏中将不会显示任何图片或播放任何音频。

默认为禁用。

### system.saveFiles：存档数量

控制存档数量，为10-99之间的整数。

默认为10个存档。

### system.collapseBlankLines：是否自动压缩空行

启用后会自动将相邻且重复的空行压缩为一行、相邻且重复的分割线压缩为一条、并将相邻分割线的空行压缩。

默认为禁用。

### system.hideUserInput：是否隐藏用户输入

启用时会隐藏用户的任何输入，包括按钮的选择在内。

默认为禁用。

### system.disableClear：是否禁止清屏

启用时引擎不再清空屏幕，并无视所有清屏指令。

慎用这个配置，因为EraElectron的UI本质是HTML，如果不清屏让内容累积下来的话会变得卡顿（可以想象一下用浏览器打开一个非常长的网页）。

默认为禁用。

### system.extendedCharaTables：扩展角色表（无法在引擎中设置）

引擎会将该变量中的表名按照角色相关的表进行处理，具体细节可见 [#9 静态数据文件](./09-static#开发者自定义的扩展表)。

默认为空数组。

### system.static：静态数据文件格式（无法在引擎中设置）

引擎会按照该变量的取值选择相应的静态数据文件进行读取，具体细节可见 [#9 静态数据文件](./09-static#相关游戏配置)。

默认为字符串"csv"。

## window.\*：窗口配置项

窗口配置项主要用于控制游戏引擎窗口，包括高度、宽度等。

![窗口配置项](../imgs/4-游戏设置-窗口.png)

### window.width：宽度（像素）

以像素为单位的窗口宽度（不包括边框），640-3840之间的整数。

此外，玩家可以手动拖动窗口来控制宽度，但无法拖动到640像素以下。

默认为1000（像素）。

### window.height：高度（像素）

以像素为单位的窗口高度（不包括边框、标题栏和菜单栏），480-2160之间的整数。

此外，玩家可以手动拖动窗口来控制高度，但无法拖动到480像素以下。

默认为880（像素）。

### window.fontSize：字号（像素）

以像素为单位的标准字号，12-36之间的整数。输出文本时的大小设置如果以rem为单位，最终大小将以该配置项为标准，具体细节可见 [#6 输出](./06-output#eraprint)。

默认为16（像素）。

### window.audio：音量

游戏播放音频的音量，0-100之间的整数。

默认为100（即最大）。

### window.autoMax：是否自动最大化

加载并进入游戏后是否自动将窗口最大化，禁用后每次重新加载游戏并进入后都会将窗口强制窗口化，反之则强制最大化。

默认为禁用。

### window.orientation：屏幕方向（安卓）
_PC引擎3.6.0、安卓引擎1.0.8及以上版本_

安卓版引擎运行游戏时的屏幕方向：

* 强制竖屏：游戏将以设备的短边作为顶边和底边显示；
* 自动：系统默认的屏幕方向；
* 强制横屏：游戏将以设备的长边作为顶边和底边显示。
