目前笔者介绍的 era.print 系 API 仅能在屏幕上输出一行内容，虽然可以通过文本换行、对齐方式等方式进行排版，但无法像下图一样将不同类型的显示内容显示在同一行：

![排版示例](../imgs/41-排版示例.png)

在本章，笔者将介绍如何通过在同一行中输出不同类型的内容进行排版，首先介绍排版的基本原理，EraElectron引擎显示界面的行列结构，并解释 era.print 系 API 中 config 参数共同的变量属性 offset 和 width 的作用，然后介绍如何使用 era.printMultiColumns 和 era.printInColRows 进行排版。

# 行列结构

EraElectron的前端显示以Vue.js为基础框架，各种界面元素和组件则来自Element Plus，因此界面布局和基础排版也来自于Element Plus[^1]。

[^1]: [Element Plus](https://element-plus.org/zh-CN/)

如果看完本节之后还对界面元素布局有疑惑，可以参考 [Layout 布局 | Element Plus](https://element-plus.org/zh-CN/component/layout.html)。

## 行（Row）与列（Column）

EraElectron显示界面由称为网格（Grid）的基本元素构成。网格是一种由一系列用于组织内容的相交的直线（垂直+水平）组成的二维结构[^2]。基于 Element Plus，EraElectron的网格系统并不是固定的，而是可以随窗口的变化而变化。如 [#7 调试 中 ere.showLines](./07-debug#ere-对象) 所示，EraElectron的显示界面被分割为很多行（Row）。在每行中，显示界面会被进一步分割，称为列（Column），一行中固定有24个列。在游戏窗口大小固定的情况下，行的高度随内容的变化而变化，而每一列的宽度则会是窗口宽度的1/24。

![行列结构](../imgs/42-行列结构.png)

[^2]: [Bootstrap 网格系统](https://www.runoob.com/bootstrap/bootstrap-grid-system.html)，Element Plus 乃至 EraElectron使用的网格系统与之类似。

EraElectron的网格系统如上图所示。可以看到，界面分为很多行，而每行则可分割为数段，每段分别占据了不同数量的列；也可以理解为每行分割为24个网格，然后网格和网格自由组合合并成为了更大的网格。

因此，先将要显示的内容分散到不同的行中，然后决定它们分别占据多少列，就是ere游戏的基本排版方法。

> 这也解释了EraElectron关于显示的行在编程和显示意义上的区别：编程意义上的行指的是 Row，是形成网格的水平状的两条相邻直线之间的内容，与之相对应的是 era.print 系 API 每次调用都会产生的 Line，本质为控制 Row 显示内容的控制对象；在显示意义上的行则是文本、图片和按钮等实际显示内容的行。

## 偏移量（offset）与宽度（width）

大多数 [era.print 系 API](./06-output#eraprint-系-api) 的参数 config 中都有 offset（偏移量）和 width（宽度）两个 Number 类型的属性。偏移量可以控制输出内容所在的网格与之前的网格之间的空白间距，而宽度则控制的是输出内容所在的网格的宽度，它们的单位都是列（Column）。

![偏移量与宽度](../imgs/43-偏移量和宽度.png)

上图较好地反映了偏移量与宽度在显示界面中的作用。通过设置偏移量和宽度，就可以将显示内容在显示界面中按一定规律分散，达到排版的效果。

![超出显示范围](../imgs/44-超出显示范围.png)

offset 的取值范围为0-23，width 的取值范围为1-24。如果 offset + width 超过24时，会产生一个超出显示宽度的网格。例如上图中输出了一个 offset 为12，width 为18的进度条，可见进度条超出显示范围的部分直接消失了，需要拖动横向滚动条才能全部显示。出于界面美观性和易用性的考虑，请尽量避免这种情况。

注意 width（宽度）指的是显示内容所在网格所占的列数，对文本、按钮等显示内容而言并不是内容的实际宽度。当文本的显示内容超出网格的宽度时，文本会出现自然换行；当按钮的显示内容超出网格宽度时却不会。因此在安排显示内容的宽度时要特别注意宽度应尽可能紧凑地正好容纳要显示的内容，避免显示效果因不合时宜的换行或者不换行而出现偏差。

## 换行与行高

当一（编程）行（Row）中的网格偏移量和宽度之和均小于24、且总偏移量和宽度之和大于24时，这些网格会像普通的文字一样自动换（显示）行。此时，行（Row）的高度会自动增加以适应显示内容。在换行前的网格所在的（显示）行的高度则会**按照最高的网格确定**。这一特性以及因此导致的变化会在 [用于在一行内输出多个内容的 API](#eraprintmulticolumns-的不足) 中进一步介绍。

# 用于排版的 API

基于EraElectron显示界面的网格系统，可以将要显示的内容在多个行中有序分散，构造美观且清晰的游戏界面。可以使用 era.printMultiColumns 和 era.printInColRows 这两个 API 来进行实现。这两个 API 可以接受对象类型的参数来指定一行内的多个显示内容，因此在使用之前，还需要将显示内容转换为对应的对象。

## 用对象表示显示内容

![GridObject](../imgs/45-GridObject.png)

era.printMultiColumns 和 era.printInColRows 中使用的用于表示显示内容的对象（可称为**网格对象**）如上图所示。该对象有六种可能的取值，分别表示按钮、分割线、图片、进度条、文本和全图六种类型，与 era.printButton、era.drawLine、era.printImage、era.printProgress、era.print 和 era.printWholeImage 六个 API 相对应。该对象可根据以下规则从对应的 API 构造：使用 type 指定对象对应显示内容的类型，然后将传给 API 的参数分别以参数名为对应属性名设置属性即可。用于表示图片和全图的对象因为涉及多媒体资源的注册和显示，将在 [#16 多媒体资源处理](./16-resources) 具体进行介绍。

### 按钮对象

`type='button'`时，该对象可表示一个按钮。

![ButtonObject](../imgs/45.1-ButtonObject.png)

如上图所示，除 type 属性外，该对象还需要 accelerator（Number 类型）和 content（String 类型）两个属性，分别对应快捷键和按钮的内容，config 属性则和 [era.printButton 中的 config 参数](./06-output#eraprintbutton) 相同。

### 分割线对象

`type='divider'`时，该对象可表示一个分割线。

![DividerObject](../imgs/45.2-DividerObject.png)

如上图所示，除 type 属性外，该对象的 config 属性和 [era.drawLine 中的 config 参数](./06-output#eradrawline) 相同。

### 进度条对象

`type='progress'`时，该对象可表示一个进度条。

![ProgressObject](../imgs/45.3-ProgressObject.png)

如上图所示，除 type 属性外，还需要 percentage（Number 类型）、inContent（String 类型）和 outContent（String 类型）三个属性，分别对应进度、进度条内的文字、进度条外的文字，config 属性和 [era.printProgress 中的 config 参数](./06-output#eraprintprogress) 相同。

### 文本对象

`type='text'`时，该对象可表示一段文本。

![TextObject](../imgs/45.4-TextObject.png)

如上图所示，除 type 属性外，content 和 config 属性和 [era.print 中的参数](./06-output#eraprint) 相同。

## era.printMultiColumns：在一行中输出多个内容

![era.printMultiColumns](../imgs/47-era.printMultiColumns.png)

主要用于在一行（Row）中输出多个列（Column）的 API。主要有两个参数，gridObjects 的类型是网格对象的数组，config 则是整体上控制这些网格对象对应的显示内容的设置。

### 基本用法

有了 era.printMultiColumns，就可以将不同类型的显示内容在其中随意组合，例如在`#/main.js`中输入以下内容：

```javascript
const era = require('#/era-electron');

module.exports = async () => {
  era.printMultiColumns([
    { config: { width: 6 }, content: '一段文本', type: 'text' },
    {
      accelerator: 1,
      config: { width: 6 },
      content: '一个按钮',
      type: 'button',
    },
    { config: { width: 6, content: '分割' }, type: 'divider' },
    {
      config: { barWidth: 12, width: 6 },
      inContent: '一个',
      outContent: '进度条',
      percentage: 90,
      type: 'progress',
    },
  ]);
};
```

然后在引擎中加载游戏，显示如下内容：

![同行多内容](../imgs/49-同行多内容.png)

正如 [换行与行高](#换行与行高) 一节中所说，当剩余的空间少于接下来要显示的内容的偏移量+宽度时，显示内容会自然换行，所以可以用 era.printMultiColumns 同时输出多行内容：

```javascript
const era = require('#/era-electron');

module.exports = async () => {
  era.printMultiColumns([
    { config: { width: 8 }, content: '我占了8列', type: 'text' },
    { config: { offset: 4, width: 8 }, content: '我占了8列，偏移量4列', type: 'text' },
    { config: { offset: 2, width: 12 }, content: '空间不够了，只能换行了:(', type: 'text' },
    { content: '我很霸道，所以独自占一行', type: 'text' },
  ]);
};
```

在引擎中会显示以下内容：

![自然换行](../imgs/50-自然换行.png)

注意以上调用 era.printMultiColumns 输出的内容在编程上属于**同一行（Row）**，`await era.clear(1);`会将它们同时清除。另外，这样输出的分割线因为并不是独占一行（Row），所以不会被【自动压缩空行】设置与相邻的分割线压缩成一行分割线：

```javascript
const era = require('#/era-electron');

module.exports = async () => {
  era.drawLine();
  era.printMultiColumns([{type:'divider'}]);
  era.drawLine();
  era.drawLine();
  era.drawLine();
};
```

![不压缩](../imgs/51-不压缩.png)

### config 参数

![ColumnConfig](../imgs/52-ColumnConfig.png)

config 参数是 era.printMulitiColumns 中的一个可选参数，类型是对象，可以有如下可选属性：

> 下面解释这些属性的作用时，为了明确它们的效果，使用宽度均为7的进度条（在不设置进度条外的文本时，进度条可以占满所在网格的宽度）

* gutter：Number 类型，用于设置同一行内网格的间距，单位为px（像素）；
    
    ![gutter](../imgs/52.1-gutter.png)

* horizontalAlign：String 类型，用于设置网格的横向对齐方式，有`'start'|'center'|'end'|'space-between'|'space-around'|'space-evenly'`六种取值，分别对应左对齐、居中、右对齐、无边距等距分散、半边距等距分散（边距会是网格间距的一半）、完全等距分散（边距和间距完全相等），默认值为`'start'`；

    ![horizontalAlign](../imgs/52.2-horizontalAlign.png)

* verticalAlign：String 类型，用于设置网格的纵向对齐方式，有`'top'|'middle'|'bottom'`三种取值，分别对应上对齐、居中、下对齐，默认值为`'top'`，主要在同一行的显示内容的高度不同的情况下生效；

    ![verticalAlign](../imgs/52.3-verticalAlign.png)

* offset：Number 类型，偏移量；
* width：Number 类型，宽度。

EraElectron引擎显示界面的网格系统是可以嵌套的，可以将一个网格继续分割成行（Row）列（Column），形成新的、更小的网格。era.printMultiColumns 的 config 参数中的 offset 与 width 可以设置这个具有多个子网格的大网格本身的偏移量和宽度，这些子网格的列宽就会根据大网格的宽度而变化。例如，如果在 era.printMultiColumns 的 config 参数中设置 `width=20`，输出一个 `width=8` 的进度条，则这个进度条的宽度会是 era.printMultiColumns 占据的大网格宽度的 `8/24=1/3`，也就是界面宽度的 `20*8/24*24=5/18`。

## era.printInColRows：在一行中输出多列内容

### era.printMultiColumns 的不足

[换行与行高](#换行与行高) 一节中提到，同一行（Row）中的网格会自然发生换行。如果将网格视为独立的、没有内部结构的显示内容，则它们所在的显示行的高度会是最高网格的高度。在少数情况下，这会使显示内容无法密铺，影响显示效果。

```javascript
const era = require('#/era-electron');

module.exports = async () => {
  era.printMultiColumns([
    { config: { color: '#e978d3', width: 8 }, content: '我很矮', type: 'text' },
    { config: { color: '#ff8e24', width: 8 }, content: '但是我们身边有个高个', type: 'text' },
    {
      config: { color: '#c0c0c0', width: 8 },
      content: '我有三行\n所以\n把大家撑高了',
      type: 'text',
    },
    {
      config: { color: '#5d7ace', width: 8 },
      content: '我想和上面的贴贴\n但是不能了呜呜',
      type: 'text',
    },
  ]);
};
```

![阻碍密铺](../imgs/53-无法密铺.png)

为了解决这个问题，笔者利用EraElectron显示界面中网格系统可以嵌套的特性，开发了 API era.printInColRows，将输出在同一行（Row）内的显示内容分割为两个嵌套的子行（Row）内，就可以使它们的高度不会彼此影响、导致无法密铺了，这就是列内行（In-column Rows）。

### 基本用法

![era.printInColRows](../imgs/48-era.printInColRows.png)

主要用于在一行（Row）中输出复杂行列结构的 API，首先会将一行（Row）视为一系列大网格（占据一个或多个 Column）的组合，然后将每个大网格再视为一个单独的子行（Row），再在其中的网格（占据一个或多个 Column）显示一系列内容，也就是一层网格系统的嵌套。

era.printInColRows 的参数名为 columnObjects。这个参数是一个可变参数，本质上是一个数组，在 era.printInColRows 中传入的参数都会成为这个数组的一个元素。因为每个参数都对应一个大网格，即 era.printMultiColumns 输出的结构，所以内容上与 era.printMultiColumns 的参数定义相同。

具体可见如下的例子：

```javascript
const era = require('#/era-electron');

module.exports = async () => {
  era.printInColRows(
    {
      columns: [
        {
          config: {
            content: '第一个大网格',
          },
          type: 'divider',
        },
        { config: { color: '#e978d3'}, content: '我很矮', type: 'text' },
        { config: { color: '#5d7ace'}, content: '我想和上面的贴贴\n贴到了嘿嘿', type: 'text' },
        {
          config: { content: '第一个大网格' },
          type: 'divider',
        },
      ],
      config: { width: 11 },
    },
    {
      columns: [
        {
          config: { content: '第二个大网格' },
          type: 'divider',
        },
        {
          config: { color: '#ff8e24', width: 12 },
          content: '我身边有个高个',
          type: 'text',
        },
        {
          config: { color: '#c0c0c0', width: 12 },
          content: '我有三行\n所以\n把大家撑高了',
          type: 'text',
        },
        {
          config: { content: '第二个大网格' },
          type: 'divider',
        },
      ],
      config: { offset: 1, width: 12 },
    },
  );
};
```

![行内列](../imgs/54-行内列.png)

### era.setHorizontalAlign 和 era.setVerticalAlign

era.printInColRows 可以在一行（Row）内输出多个带有子网格结构的大网格，但是 era.printInColRows 没有对这一行（Row）整体设置的参数，那么如何设置这些大网格的对齐方式呢？这就需要用到 era.setHorizontalAlign 和 era.setVerticalAlign。这两个 API 分别会设置 era.printInColRows 输出的大网格的横向和纵向对齐方式（但仅影响 era.printInColRows），参数的具体取值可见 [era.printMultiColumns 的 config 参数](#config-参数)。注意在输出结束之后再改回默认值（`'start'`和`'top'`），以免影响下次输出。

### era.replaceInColRows

和 [era.replaceText](./06-output#erareplacetext) 类似的 API，会将此前最后输出的行替换成具有复杂行列结构的行（Row）。其参数与 era.printInColRows 完全一致。

注意替换的是**此前最后输出的行**，也就是说如果未设置【隐藏用户输入】，即使输出的玩家输入的内容也会被替换。

## era.setOffset 和 era.setWidth

主要用于设置默认偏移量和宽度的 API，参数都是 Number 类型，在想统一设置后续显示内容的偏移量和宽度的时候很有用。

但因为修改了默认行为，记得在想要控制的内容显示之后重置回初始默认值。偏移量的初始默认值为0，宽度的初始默认值为24。

# 小结

本章介绍了如何在同一行中组织输出不同显示内容的方法，包括基础原理EraElectron引擎显示界面的行列结构和网格系统，利用这种网格系统进行排版的 API era.printMultiColumns 和 era.printInColRows，以及这些 API 的使用细节和相关的辅助 API。在此基础上，开发者就可以妥善安排界面上的显示内容，绘制美观且清晰的游戏界面。
