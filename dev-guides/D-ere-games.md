# 游戏

## EraUma

愛若駑馬（EraUma）是以某頁遊公司旗下馬耳學生妹作品爲世界觀製作的一款同人文字冒險遊戲。該世界觀的核心圍繞娘化的名賽馬和歷史上曾發生過的比賽展開。玩家將在遊戲中扮演訓練員——即負責訓練馬娘的角色——與諸多馬娘邂逅並創作獨屬於玩家和其負責馬娘的故事。

- 官方代码仓库：[UmaERA / EraUma · GitLab](https://gitgud.io/umaera/erauma)
- 下載連結：[EraUma最新版本](https://gitgud.io/umaera/erauma/-/releases/permalink/latest)
- 游戏攻略与其他信息：[Wiki](https://gitgud.io/umaera/erauma/-/wikis)
- 官方社区：[ERA特雷森学园](https://discord.gg/ake5SP3zUP)
- 非官方安卓版：[Erauma_Android_Game最新版本](https://gitgud.io/erauma_android_unofficial_port/erauma-android-game/-/releases/permalink/latest)

## ereKanon

[erakanon](https://cbaku2.sakura.ne.jp/b/2010/12/eramaker/) 的 ere 移植版本。erakanon 是首款使用 eramaker 运行的、狭义意义上的第一款 era 游戏，奠定了 ERA 游戏的基本游戏模式。

- 官方代码仓库：[UmaERA / 游戏 / ereKanon · GitLab](https://gitgud.io/umaera/game/ere-kanon)
- 下载链接：[ereKanon最新版本](https://gitgud.io/umaera/game/ere-kanon/-/releases/permalink/latest)

# 引擎

## EraElectron

_Win、Mac、Linux_

基于 Electron 的 ERA 游戏引擎，支持使用 Javascript 进行 ERA 游戏开发，使用 element-plus 提供基本页面元素和排版功能。

- 官方代码仓库：[UmaERA / 引擎 / EraElectron-基于Electron的ERA引擎 · GitLab](https://gitgud.io/umaera/engine/era-electron)
- 下载链接：[EraElectron 最新版本](https://gitgud.io/umaera/engine/era-electron/-/releases/permalink/latest)
- 使用教程：[Wiki](https://gitgud.io/umaera/engine/era-electron/-/wikis)

## ere.app

_Android_

基于capacitor+vue+element-plus的跨平台ERA游戏引擎。

- 官方代码仓库：[UmaERA / 引擎 / ere.app · GitLab](https://gitgud.io/umaera/engine/ere-app)
- 下载链接：[ere.app最新版本](https://gitgud.io/umaera/engine/ere-app/-/releases/permalink/latest)
