# 移植存根清单

**用途**：一处列全「原作函数 → 归属」的待办清单。后续票（或认领者）据此找到
待实现项；新增存根必须同步登记本清单（`ere/event/event-first.js` 导出的
`STUBBED_CALLS` 有测试与本文档核对，见 `test/event-first.test.js`）。

**检索**：按原作函数名搜本文件即可（如 `rg RAND_CHARA_MAKE docs/`）；
运行时占位行、代码内注释均带同样的函数名，三处互为印证。

**状态含义**：

- **存根（运行时占位）**：调用点已接入，执行到时打一行占位反馈（含函数名）；
- **登记（不可达 / 未接入）**：调用点所在的分支当前不可达，或调用点本身尚未
  移植，仅登记防遗忘。
