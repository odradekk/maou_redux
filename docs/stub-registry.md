# 移植存根清单

**用途**：一处列全「原作函数 → 归属」的欠账地图。后续票（或认领者）据此找到
待实现项；新增存根必须同步登记本清单（`ere/event/event-first.js` 导出的
`STUBBED_CALLS` 有测试与本文档对账，见 `test/event-first.test.js`）。

**检索**：按原作函数名搜本文件即可（如 `rg RAND_CHARA_MAKE docs/`）；
运行时占位行、代码内注释均带同样的函数名，三处互为印证。

**状态含义**：

- **存根（运行时占位）**：调用点已接线，执行到时打一行占位反馈（含函数名）；
- **登记（不可达/未接线）**：调用点所在的分支当前不可达、或调用点本身尚未
  移植，仅登记防遗忘。

## 维护规则

1. 新存根：代码内注释 + 运行时占位（可达路径）带原作函数名，本清单加一行；
   `STUBBED_CALLS` 若涉及须同步（有测试对账）。
2. 认领实现：改本清单该行状态为「已实现（票号/PR）」，或整行移除并在对应
   票留痕——地图 issue #1 只读，欠账变化以本清单为活文档。
3. 本清单只收「原作有、ere 侧欠」的项；ere 侧新增机制（如状态机）不在此列。
