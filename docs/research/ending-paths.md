# 结局体系与最短通关路径

对应工单：[issue #102](https://github.com/odradekk/maou_redux/issues/102)（路线图 #101）。
调查对象：`target/`（Emuera 版《ERA魔王 年度版》简体汉化版，只读输入）。
方法：直读 `target/ERB/` 源码，所有论断带 `文件:行号`；日文原作文档（`target/資料_非必要無須解壓/`）仅作佐证，与代码冲突时以代码为准。

## 结论摘要

1. 结局分四层：**主线结局 6 个**（`ENDING_1`~`ENDING_5`、`ENDING_N`）、**角色线结局 4 族 68 个分支**（`END7_*`/`END10_*`/`END11_*`/`END14_*`）、**隐藏 GAMEOVER 2 处**（`ENDING_2` 魔王城陷落、`DEBUG_CHECK` 大冲击）、以及**只有 flag 没有剧情的 9 条死线**（`END2/3/4/5/6/8/9/12/13/15_*` 族函数不存在，`TRYCALLFORM` 静默空转）。
2. 判定入口 `@ENDCHECK` 挂在日循环上，每天午后执行一次（`EVENT_NEXTDAY.ERB:241`）；侵略结局由每次侵略结算后的 `@INVASION_CHECK` 触发（`侵略/INVASION.ERB:996`）。
3. **最短通关路径是侵略线：新游戏 → 初始设置 → 主菜单 [109] 反复用魔力出兵，约 55–70 个游戏日堆满人间界侵攻度 10000，触发 `ENDING_1`（Good End）**。Normal End 硬门槛 500 天；角色线结局依赖调教积累与多阶段计数器，周期更长。
4. 推荐终点判定用 **`ENDING_1`**：条件单一确定、主动达成、演出完整、路径覆盖五个核心子系统（理由见第五节）。

## 一、结局体系的运行机制

### 判定入口与调用链

```
EVENTTURNEND（#PRI，EVENT_TURNEND.ERB:8）
  └ TIME==1 时 CALL EVENT_NEXTDAY（EVENT_TURNEND.ERB:77）→ DAY:0 += 1（:79）
      └ CALL ENDCHECK（EVENT_NEXTDAY.ERB:241，注释「主线剧情监测」，每日一次）
          ├ CALL ENDRESET          每日清场：剧情角色不在场则清对应线 flag（ENDINGDATA.ERB:1-35）
          ├ CALL ENDCHECKMAIN      全局判定（ENDINGDATA.ERB:38-63）
          ├ CALL ENDCHECKCHARA     角色线推进（ENDINGDATA.ERB:64-140）
          │   ├ CALL ENDCHECKSPADE            银黑桃线（:208）
          │   ├ CALL ENDCHECKSQUARE           黑方片线（:143）
          │   ├ CALL ENDCHECKGODNESS          嘉德线（ENDINGDATA_ADDON1.ERB:1）
          │   ├ CALL ENDCHECKGODNESS_SKY_TEMPLE 嘉德离队后的天神宫线（同文件:146）
          │   └ CALL ENDCHECKPRINCESS         菲娅线（:353）
          ├ TRYCALLFORM END{2..15}_{阶段}    分支剧情演出分派（ENDING ver 1.0.1.ERB:345-348）
          ├ CALL ENDING_N           Normal End（:351-352）
          └ TRYCALL END31           死引用，已登记 #14（:354-356）
```

另一条独立入口：每次侵略出兵结算后 `CALL INVASION_CHECK`（侵略/INVASION.ERB:996），任一区域侵攻度满 10000 即触发对应主线结局（:1001-1021）。

### 全局判定 ENDCHECKMAIN 的五条线（ENDINGDATA.ERB:38-63）

| flag           | 条件                                        | 效果                                                                                                        |
| -------------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `EX_FLAG:2801` | `DAY:0 == 500` 且主线空闲（`=0` 或 `>=90`） | 置 99，随后 `CALL ENDING_N`（:43-44；ENDING ver 1.0.1.ERB:351-352）                                         |
| `EX_FLAG:2802` | `MONEY > EX_FLAG:4444 + 8766`               | 置 10（:46-47）。`EX_FLAG:4444` 是「非作弊获得的资金」追踪器，见 `@MONEYSYS`（SYSTEM ver1.0.3.ERB:983-986） |
| `EX_FLAG:2803` | 任一奴隶 `CFLAG:9 >= 5000` 且非助手         | 记录该角色编号（:52-55）                                                                                    |
| `EX_FLAG:2804` | 魔王自己 `CFLAG:0:9 >= 1500`                | 置 10（:58-59）                                                                                             |
| `FLAG:2816`    | `EX_FLAG:99 <= 0`（威望耗尽）               | 置 10（:62-63）。全库无消费点，死代码                                                                       |

2802/2803/2804 的真实消费者是 `@DEBUG_CHECK`（反作弊，EVENT_TURNEND.ERB:170-334）：凭空多钱触发哥布林炸宝库（资金清零+随机角色死亡，:187-235）；奴隶魔力过载触发暴走炸死（:237-308）；魔王自己过载触发**【大冲击】GAMEOVER 并强制退出**（:310-332）。这是三条线里唯一的真终局。

### 编号分派机制

`ENDCHECK` 末尾（ENDING ver 1.0.1.ERB:344-349）：

```erb
IF EX_FLAG:2801 != 99
    FOR LOCAL,2,16
        SIF EX_FLAG:(2800+LOCAL)%10 == 0
            TRYCALLFORM END{LOCAL}_{EX_FLAG:(2800+LOCAL)/10}
    NEXT
ENDIF
```

即 `EX_FLAG:28xx` 的**百位以上是线号**、**十位是小节**、**个位为 0 才演出**（防重播）。`TRYCALLFORM` 对不存在的函数名静默跳过——这掩盖了大量半成品线（见第六节）。

### 角色线结局（四族，共 68 个分支）

共同结构：剧情角色在场（`GETCHARA(n) > 0`）→ 素质定线（`TALENT:85`=恋慕、`TALENT:76`=淫乱）→ 好感（`CFLAG:2`）与阶段计数器（`CFLAG:515`）逐级推进 → 各阶段当日演出 `END{n}_{节}` → 末段内联问「想进入这个结局吗」，选 1 播真结局演出并把 `EX_FLAG:2801` 抬到 `>= 91`（此后 500 天的 `ENDING_N` 收尾）。

| `END10_*` | 嘉德（33，经 `ENDING_5` 进队） | `ENDCHECKGODNESS`（ADDON1:1-144）+ `SKY_TEMPLE`（:146-153） | 13 个（:155-704）   | `END10_19` 淫乱天神——**不可达**（见下）         |
| `END11_*` | 黑方片（22）                   | `ENDCHECKSQUARE`（ENDINGDATA.ERB:143-207）                  | 10 个（:819-1102）  | `END11_9` 傲娇商贾后裔                          |

各族关键门槛（条件原文所在行）：

- **恋慕线推进**：好感 2000 → 5000 → 10000（如 ENDINGDATA.ERB:157-164），中期 `(ABL:10 + ABL:16) >= 14`（:166），后期 `CFLAG:515` 计数器 10/30/60/100/150（:170-198）。
- **淫乱线**平行存在（`TALENT:76`），银黑桃淫乱线 140→150 段额外要求 `ABL:1 == 10 && ABL:17 == 5 && TALENT:78 == 1 && TALENT:0 == 0`（:319）。
- **生死分岔**：黑方片/银黑桃的 `END11_4`/`END14_4`（:913、:1171）二选一——放走则该角色离队（`DELCHARA`），转 300 段，最终 `END11_31`/`END14_31` 是狂王水晶球宣告其死亡；不放则转淫乱线 50 段。
- **嘉德线 150 段以后全部不可达**：推进条件 `DAY:1 >= 350`（ADDON1:105、112、119、126、133），而 `DAY:1` 是**月份**（EVENT_NEXTMONTH.ERB:3 注释「DAY:1は现在の月」，1–12 循环，:14-35），条件恒假。连带 `END10_15`~`END10_19` 六个分支永不演出——包括全库唯一把 `EX_FLAG:2801 = 99` 的真结局 `END10_19`。
- **天神宫线（`END10_54/55`，500 段）**：离队后的嘉德线，`SKY_TEMPLE` 判定要求 `FLAG:93 == 3`（ADDON1:151-152）；`END10_55` 另有 `INVASION_CHECK` 直调（INVASION.ERB:1017），条件 `EX_FLAG:101 >= 10000`，但全库未发现 `EX_FLAG:101` 的写入点，判定为不可达（未确认是否存在 `CALLFORM` 拼名写入）。
- 菲娅线有一个无出口的 `-10` 状态（好感线崩坏，ENDINGDATA.ERB:374-375），设进去后无法继续推进。

### 只有 flag、没有剧情的线（9 条）

`ENDCHECKCHARA` 为玛奥（17）、莉莉（24）、琼（31）、普林希斯（32）、白梅花（23）、金红桃（20）、葵希罗（34）都设了起步 flag（ENDINGDATA.ERB:66-137），但 `END5/6/8/9/12/13/15_*` 族函数**全库无定义**，分派 `TRYCALLFORM` 静默空转。`ENDINGINPUT` 的通用分支对这些线也只回「此处剧情尚未做好」（ENDING ver 1.0.1.ERB:977）。另：

- 葵希罗的进度存 `FLAG:2815`（:130-136，注意是 `FLAG` 不是 `EX_FLAG`），而分派循环读 `EX_FLAG:2815`（:345-347），变量族错位，即使有函数也调不到。
- 玛奥线的「双飞 end」在 `ENDINGINPUT CASE 16` 明示「此处剧情尚未做好」（:958-967）。
- `其他/TEST.ERB:1` 的 `@ENDCHECKDRAGONSIS`（普林希斯龙妹线判定状态机）无任何调用者，是开发残留死代码。

## 三、最短通关路径

### 候选线对比

| ---------------------------------- | ------------------- | -------------------------------------------------- | -------------------------------------------------------------------------- |
| **侵略线**（`ENDING_1`）           | 主菜单 [109] 侵略   | **约 55–70 游戏日**（估算见下）                    | **最短**                                                                   |

### 天数估算与假设

参数全部来自源码：魔王气力开局即满（`target/CSV/Chara/Chara0.csv` 基礎 1 = 10000）；每个时段出兵一次（气力减半、贡献 `气力/25`），两次休息分别回 1400/1000。稳定态出兵前气力约 2267/2533，**日毛增约 192 点**；扣自然衰减均值 50/日，**日净增约 142 点**；叠加开局满气力的前期红利，**堆满 10000 约需 55–70 个游戏日**。参数敏感：若威望跌破 60（每次侵略 `EX_FLAG:99 += 2` 是加分项，事件可能扣分），出兵效率按区间打折（INVASION.ERB:241-292），周期相应拉长。

### 为什么这条最短

- 500 天是 `ENDING_N` 的硬编码门槛（ENDINGDATA.ERB:43），任何操作无法缩短。
- 角色线真结局的前置（先拿到剧情角色）本身就包含一次侵略结局或长时间捕获/购买，且阶段计数器按天累计（`CFLAG:515` 需 10→150 共 5 级），总周期只会更长。
- 侵略线**完全不经过调教**（`BEGIN TRAIN` 循环）、迷宫探索、商店购物与口上系统；开局资源（10000 资金 + 满气力 + 威望 70）已满足全部门槛。

## 四、关键路径子系统清单（供阶段划分引用）

侵略最短线必经（按路径顺序）：

1. **SYSTEM**：标题画面（`TITLE ver1.0.8.ERB`）、初始设置（`FIRST_SETTING`）、`@EVENTFIRST`。
2. **SHOP 主菜单**：`DRAW_MAINMENU.ERB` 绘制、`SHOP ver1.0.2.ERB` 分派（[109]/[199] 两个入口）。
3. **日循环**：`EVENTTURNEND` 双实现（#PRI 版推进时段与日期，EVENT_TURNEND.ERB:8-140；无属性版做恢复/衰减/装备/自动事件，SYSTEM ver1.0.3.ERB:234-758）、`EVENT_NEXTDAY`（含 `ENDCHECK` 日检与晨间事件）、`EVENT_NEXTMONTH`。
4. **侵略**：`INVASION.ERB` 的菜单/魔力出兵/结算/`INVASION_CHECK` 一条窄路径，及 `KYOTEN_EVENT` 据点事件（侵攻度 2000/4000/6000/8000/10000 触发，INVASION.ERB:980-994）。
5. **结局系统**：`ENDING_1` 演出、`CHAR_GIFT` 贡品流程（`ENDING_3/4/5` 才走）、`ADDCHARA_EX`/`CHAR_INIT` 角色入队。
6. **结局判定链（必须存在但可空转）**：`ENDCHECK` → `ENDRESET`/`ENDCHECKMAIN`/`ENDCHECKCHARA` 全链——它每天执行，任何一环缺失都会改变主线行为。

路过但不深入：`EVENTTURNEND` 每日扫过的装备检查、`LVUP`、`AUTO_BUYING`、自动调教等（不操作则空转）。

可整体绕开：调教主循环（`TRAIN_MAIN`，47K 行的 `調教相關/`）、迷宫（`迷宮/`）、商店交易与裁缝、处刑、妊娠、`其他/` 六子系统（LOVERS/MAGIC/FUNC_CLOTH/EQUIP/NINSIN/USE_EX_ITEM）的非装备检查部分、全部口上（149K 行）、campaign（[9] 向着世界之外，不选不进）。

## 五、推荐终点判定：`ENDING_1`

理由：

1. **条件单一且确定**：`FLAG:81 >= 10000 && FLAG:82 == 0`（INVASION.ERB:1001），无随机、无隐藏前置；对照 `ENDING_2`（要勇者恰好活着走到第 9 层）与大冲击（数值失控的失败态）都不可作为验收目标。
2. **主动达成、周期最短**：55–70 天 vs Normal End 的 500 天，验收成本低一个量级。
3. **演出完整可判定**：横幅文本 + 菲娅入队 + `FLAG:82 = 1` 副作用，三个可断言信号（文本、角色表、flag），对拍容易。
4. **覆盖面合适**：路径串起 SYSTEM → SHOP → 日循环 → 侵略 → 结局五个子系统，正好是「从新游戏走到一个结局」的最小验证面；且不依赖调教与口上，避免把最重的两个子系统拖进终点判定的关键路径。
5. **一个注意点**：`ENDING_1` 是中场结局，演出后游戏可继续（选项 0）。终点判定应取「`ENDING_1` 演出已出现」（`FLAG:82 == 1` 即为其完成标记），而不是游戏退出。
