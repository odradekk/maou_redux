# 结局体系与最短通关路径

对应工单：[issue #102](https://github.com/odradekk/maou_redux/issues/102)（路线图 #101）。本文记录结局体系的结构分析与最短通关路径结论，供理解结局判定与端到端验收参考；函数与变量以 `ere/` 现状为准。缺陷类条目按 #574 由阶段 7 的缺陷工单逐个处理。

分支演出登记在 `ere/data/ending-scripts.js` 的 `END_SCRIPTS`，按族号、节号两级索引（菲娅线第 12 节是 `END_SCRIPTS[7][12]`）。下文用 `END7_12` 这类写法指代同一件事。

## 结论摘要

1. 结局分四层：**主线结局 6 个**（`ending_1`~`ending_5`、`ending_n`，`ere/event/event-ending.js`）、**角色线结局 4 族 68 个分支**（`END7_*`/`END10_*`/`END11_*`/`END14_*`）、**隐藏 GAMEOVER 2 处**（`ending_2` 魔王城陷落、`debug_check` 大冲击）、以及**10 个无脚本的分支族**（`END2/3/4/5/6/8/9/12/13/15_*`，分派静默空转）。
2. 判定入口 `run_endcheck`（`ere/event/event-endcheck.js`）挂在日循环上，每天午后回合结束、进入次日时执行一次；侵略结局由每次侵略结算后的 `invasion_check`（`ere/page/page-invasion.js`）触发。
3. **最短通关路径是侵略线：新游戏 → 初始设置 → 主菜单 [109] 反复用魔力出兵，约 100 个游戏日堆满人间界侵攻度 10000，触发 `ending_1`（Good End）**（#120 端到端实测 100 日，初稿曾按「每日一次衰减」估为 55–70 日，勘误见「天数估算与假设」）。Normal End 硬门槛 500 天；角色线结局依赖调教积累与多阶段计数器，周期更长。
4. 推荐终点判定用 **`ending_1`**：条件单一确定、主动达成、演出完整、路径覆盖五个核心子系统（理由见第五节）。

## 一、结局体系的运行机制

### 判定入口与调用链

每天午后回合结束、进入次日时（`ere/event/event-turnend.js`：`era_flag.time === 1` 的回合结束调 `run_event_nextday`，结局检查在其中运行，之后才把 `time` 置 0），执行一次 `run_endcheck`：

- `endreset`：每日清场，剧情角色不在场则清对应线 flag；
- `endcheck_main`：全局判定（五条线，见下）；
- `endcheck_chara`：角色线推进，五条判定，对应四族结局——银黑桃线、黑方片线、嘉德线、嘉德离队后的天神宫线、菲娅线；
- 分支演出分派：遍历线号 2–15，多数族无脚本，静默空转；
- `ending_n`：Normal End。

另一条独立入口：每次侵略出兵结算后 `invasion_check`，任一区域侵攻度满 10000 即触发对应主线结局。

### 全局判定 endcheck_main 的五条线

| flag          | 条件                                             | 效果                                                              |
| ------------- | ------------------------------------------------ | ----------------------------------------------------------------- |
| `exflag:2801` | `day_count == 500` 且主线空闲（`=0` 或 `>=90`）  | 置 99，随后 `ending_n`                                            |
| `exflag:2802` | `era_flag.money > era_exflag.legit_money + 8766` | 置 10。`legit_money`（`exflag:4444`）是「非作弊获得的资金」追踪器 |
| `exflag:2803` | 任一奴隶 `cflag:9 >= 5000` 且非助手              | 记录该角色编号                                                    |
| `exflag:2804` | 魔王自己 `cflag:0:9 >= 1500`                     | 置 10                                                             |
| `flag:2816`   | `exflag:99 <= 0`（威望耗尽）                     | 置 10。全库无消费点，死代码                                       |

2802/2803/2804 的真实消费者是 `debug_check`（反作弊，`ere/event/event-turnend.js`）：凭空多钱触发哥布林炸宝库（资金清零 + 随机角色死亡）；奴隶魔力过载触发暴走炸死；魔王自己过载触发**【大冲击】GAMEOVER 并强制退出**。这是三条线里唯一的真终局。

### 编号分派机制

`run_endcheck` 末尾的分派循环遍历线号 2–15：读 `exflag:(2800 + 线号)`，**十位是小节、个位为 0 才演出**（防重播，演出尾部 `+= 1` 置个位），按「族号 + 节号」查 `END_FAMILY` 分发注册表（`ere/event/ending-family.js`）；`exflag:2801 == 99`（Normal End 已定）时整体短路。分派对无脚本的键返回缺省值、静默跳过——这掩盖了大量半成品线（见第二节）。

## 二、结局清单

### 主线结局

| 函数       | 内容                                                        | 触发条件与调用者                                   | 终局性                                |
| ---------- | ----------------------------------------------------------- | -------------------------------------------------- | ------------------------------------- |
| `ending_1` | Good End：征服人间界，抓人类皇族公主菲娅进队，`flag:82 = 1` | `flag:81 >= 10000 && flag:82 == 0`（侵略结算检查） | 中场结局：可选继续游戏（选 1 才退出） |
| `ending_2` | 魔王城陷落：勇者封印魔王，GAMEOVER 横幅后强制退出           | 探索者（非勇者素质）到达迷宫第 9 层魔王房间        | **强制 GAMEOVER**                     |
| `ending_3` | 征服精灵领域，献上精灵圣女琼（31）进队                      | `flag:86 >= 10000 && flag:87 == 0`                 | 中场结局，贡品入队后继续              |
| `ending_4` | 征服龙族山脉，献上龙族公主普林希斯（32）                    | `flag:88 >= 10000 && flag:89 == 0`                 | 同上                                  |
| `ending_5` | 征服天界，献上下任主神嘉德（33）                            | `flag:90 >= 10000 && flag:91 == 0`                 | 同上                                  |

### 角色线结局（四族，共 68 个分支）

共同结构：剧情角色在场 → 素质定线（`talent:85`=恋慕、`talent:76`=淫乱）→ 好感（`cflag:2`）与阶段计数器（`cflag:515`）逐级推进 → 各阶段当日演出 → 末段内联问「想进入这个结局吗」，选 1 播真结局演出并把 `exflag:2801` 抬到 `>= 91`（此后 500 天的 `ending_n` 收尾）。

| 族        | 角色（编号）                   | 分支  | 真结局                                          |
| --------- | ------------------------------ | ----- | ----------------------------------------------- |
| `END7_*`  | 菲娅（35，经 `ending_1` 进队） | 22 个 | `END7_12` 魔界公主、`END7_22` 魔女              |
| `END10_*` | 嘉德（33，经 `ending_5` 进队） | 13 个 | `END10_19` 淫乱天神——**不可达**（见下）         |
| `END11_*` | 黑方片（22）                   | 10 个 | `END11_9` 傲娇商贾后裔                          |
| `END14_*` | 银黑桃（21）                   | 21 个 | `END14_9` 忍者组织头领、`END14_20` 魔王专属乳牛 |

各族关键门槛：

- **恋慕线推进**：好感 2000 → 5000 → 10000，中期要求 `(abl:10 + abl:16) >= 14`，后期 `cflag:515` 计数器 10/30/60/100/150。
- **淫乱线**平行存在（`talent:76`），银黑桃淫乱线 140→150 段额外要求 `abl:1 == 10 && abl:17 == 5 && talent:78 == 1 && talent:0 == 0`。
- **生死分岔**：黑方片/银黑桃的 `END11_4`/`END14_4` 二选一——放走则该角色离队，转 300 段，最终 `END11_31`/`END14_31` 是狂王水晶球宣告其死亡；不放则转淫乱线 50 段。
- **嘉德线 150 段以后全部不可达**：推进条件 `era_flag.month >= 350`，而 month 是**月份**（1–12 循环），条件恒假。连带 `END10_15`~`END10_19` 六个分支永不演出——包括全库唯一把 `exflag:2801 = 99` 的真结局 `END10_19`。
- **天神宫线（`END10_54/55`，500 段）**：离队后的嘉德线，判定要求 `flag:93 == 3`；`END10_55` 另有 `invasion_check` 直调，条件 `exflag:101 >= 10000`，但 `exflag:101` 只有读取（判定与进度显示），全库无写入点，判定为不可达。
- 菲娅线有一个无出口的 `-10` 状态（`exflag:2807 = -10`，好感线崩坏）：设进去后分派算出负节号，无脚本可演，无法继续推进。

### 无脚本的分支族（10 个）

分派循环覆盖族 2–15 共 14 族，其中只有 4 族有脚本，**其余 10 族无任何实现**，分派静默空转。这 10 族分两类，成因不同：

**其一，七条有起步 flag 的角色线**：玛奥（17）、莉莉（24）、琼（31）、普林希斯（32）、白梅花（23）、金红桃（20）、葵希罗（34）都有起步 flag，但 `END5/6/8/9/12/13/15_*` 族无脚本。结局输入的通用分支对这些线也只回「此处剧情尚未做好」。

**其二，三个被反作弊计数器误占的槽位**：`exflag:2802/2803/2804` 根本不是剧情线，是 `endcheck_main` 的反作弊计数器（资金异常置 10、奴隶魔力过载记角色编号、魔王过载置 10），但它们落在分派循环的 `2800 + 线号` 范围内。2802/2804 被置 10 后 `10 % 10 == 0` 成立，于是每日分派族 2 第 1 节与族 4 第 1 节——两者都不存在，静默空转；2803 存的是角色编号，编号恰为 10 的倍数时同样触发。**这不是半成品剧情，是两套机制共用一段 flag 区间的碰撞。**

另：

- 葵希罗的进度存 `flag:2815`，而分派循环读 `exflag:2815`，变量族错位，即使有脚本也调不到。
- 玛奥线的「双飞 end」在结局输入的对应分支明示「此处剧情尚未做好」。

## 三、最短通关路径

### 候选线对比

| 候选线                             | 入口                | 最低周期                                           | 判定                                                                       |
| ---------------------------------- | ------------------- | -------------------------------------------------- | -------------------------------------------------------------------------- |
| **侵略线**（`ending_1`）           | 主菜单 [109] 侵略   | **约 100 游戏日**（#120 实测，见下）               | **最短**                                                                   |
| Normal End 线（`ending_n`）        | 挂机 500 天         | 硬门槛 `day_count == 500`                          | 慢一个量级，且需全程避开大冲击（魔王 `cflag:0:9` 达 1500 即 GAMEOVER）     |
| 角色线（`END7/11/14`）             | 获得剧情角色 + 调教 | 依赖多轮调教积累好感 2000–10000 与 250+ 天阶段计数 | 前置本身就要先打完一次侵略结局（菲娅/嘉德）或从商店/捕获获得角色；周期最长 |
| 被动 GAMEOVER（`ending_2`/大冲击） | 失败即触发          | 不可控                                             | 不算通关                                                                   |

### 侵略线逐步序列（从新游戏到 `ending_1`）

| 步  | 事件                                    | 玩家必须做的                                                                                                                                      |
| --- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 标题画面选 [1] 新的猎物                 | 清档重开：魔王（角色 0）入队，进初始设置                                                                                                          |
| 2   | 初始设置菜单                            | 必经：选魔王性别/狂王性别/初期奴隶/模式，[100] 决定                                                                                               |
| 3   | 全局初始化                              | 资金 10000、威望 70、日期起点；村娘（17）或随机初始奴隶；开场剧情后进据点主菜单                                                                   |
| 4   | 主菜单 [109] 侵略                       | 进侵略菜单，**无解锁条件**；人间界未征服（`flag:82==0`）时默认目标为人间界（AREA 81）                                                             |
| 5   | 侵略菜单选 [1] 使用魔王的魔力（经验值） | 侵攻度增量 = 当前气力 / 25，气力减半；**无兵力门槛**（怪物路线才要 600 只）。威望 70 落在 61–80「相安无事」区间，无修正                           |
| 6   | 结算与检查                              | `flag:81 >= 10000 && flag:82 == 0` 则 `ending_1`；否则回主菜单并**自动过时段**                                                                    |
| 7   | 时段循环（每日两回合）                  | 时段 0→1（气力 +1400）或 1→0（次日：结局日检、日期 +1、气力 +1000）；人间界未征服时**每回合**侵攻度自然衰减 0–99 的随机值（无时段条件——每日两次） |
| 8   | 循环 4–7 至满 10000                     | `ending_1` 演出：横幅 + 菲娅进队 + `flag:82 = 1`，询问是否继续（选 0 继续/选 1 结束）                                                             |

### 天数估算与假设

参数：魔王气力开局即满（角色 0 的基础值，上限 10000）；每个时段出兵一次（气力减半、贡献 `气力/25`），两次休息分别回 1400/1000。稳定态出兵前气力约 2267/2533，**日毛增约 192 点**；自然衰减**每回合（半天）一次、均值约 50**，**日衰减均值约 99、日净增约 93 点**；叠加开局满气力的前期红利，**堆满 10000 约需 100–110 个游戏日**。

> **勘误（#120 端到端实测）**：本节初稿按「每日一次衰减、均值 50/日」估算为 55–70 日——把每回合（半天）的衰减当成了每日一次，统计单位错了（出兵每日两次算对了，衰减漏乘了同一个 2）。#120 的端到端用例（`test/event-ending-e2e.test.js`，种子化随机源）实测**第 100 个游戏日**通关，与正确的统计单位吻合。参数敏感：若威望跌破 60（每次侵略威望 +2 是加分项，事件可能扣分），出兵效率按区间打折，周期相应拉长。

### 为什么这条最短

- 500 天是 `ending_n` 的硬编码门槛，任何操作无法缩短。
- 角色线真结局的前置（先拿到剧情角色）本身就包含一次侵略结局或长时间捕获/购买，且阶段计数器按天累计（`cflag:515` 需 10→150 共 5 级），总周期只会更长。
- 侵略线**完全不经过调教循环、迷宫探索、商店购物与口上系统**；开局资源（10000 资金 + 满气力 + 威望 70）已满足全部门槛。

## 四、关键路径子系统清单（供阶段划分引用）

侵略最短线必经（按路径顺序）：

1. **系统**：标题画面、初始设置、全局初始化。
2. **据点主菜单**：绘制与分派（[109]/[199] 两个入口）。
3. **日循环**：时段与日期推进、恢复/衰减/装备/自动事件、次日事件（含结局日检与晨间事件）、月份切换。
4. **侵略**：菜单/魔力出兵/结算/`invasion_check` 一条窄路径，及据点事件（侵攻度 2000/4000/6000/8000/10000 触发）。
5. **结局系统**：`ending_1` 演出、贡品流程（`ending_3/4/5` 才走）、角色入队。
6. **结局判定链（必须存在但可空转）**：`run_endcheck` → `endreset`/`endcheck_main`/`endcheck_chara` 全链——它每天执行，任何一环缺失都会改变主线行为。

路过但不深入：日循环每日扫过的装备检查、升级、自动购买、自动调教等（不操作则空转）。

可整体绕开：调教主循环、迷宫、商店交易与裁缝、处刑、全部口上、战役（[9] 向着世界之外，不选不进），以及杂项子系统（恋人、魔法、服装、装备、妊娠、EX 道具）除装备检查外的部分。

## 五、推荐终点判定：`ending_1`

理由：

1. **条件单一且确定**：`flag:81 >= 10000 && flag:82 == 0`，无随机、无隐藏前置；对照 `ending_2`（要勇者恰好活着走到第 9 层）与大冲击（数值失控的失败态）都不可作为验收目标。
2. **主动达成、周期最短**：约 100 天（#120 实测）vs Normal End 的 500 天，验收成本低一个量级。
3. **演出完整可判定**：横幅文本 + 菲娅入队 + `flag:82 = 1` 副作用，三个可断言信号（文本、角色表、flag）。
4. **覆盖面合适**：路径串起系统 → 据点 → 日循环 → 侵略 → 结局五个子系统，正好是「从新游戏走到一个结局」的最小验证面；且不依赖调教与口上，避免把最重的两个子系统拖进终点判定的关键路径。
5. **一个注意点**：`ending_1` 是中场结局，演出后游戏可继续（选项 0）。终点判定应取「`ending_1` 演出已出现」（`flag:82 == 1` 即为其完成标记），而不是游戏退出。

## 六、缺陷与死引用清单（#14 之外的在案记录）

| 项                      | 说明                                                                                                             |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 菲娅线第 13 节节号错位  | 该节在 `END_SCRIPTS[7]` 下登记成节号 `713`，分派查的是节号 `13`，永不命中；该段是空段，玩家侧无可观察差异        |
| 十个分支族无脚本        | 见第二节。`END2/3/4/5/6/8/9/12/13/15_*` 被分派调用但无实现，静默空转；其中 `END2/3/4` 的槽位实为反作弊计数器占用 |
| 嘉德线 150 段恒假条件   | `era_flag.month >= 350` 中 month 是月份，永不可达，`END10_15`~`19`（含唯一 `exflag:2801 = 99` 真结局）死线       |
| 葵希罗线变量族错位      | 进度写 `flag:2815`，分派读 `exflag:2815`                                                                         |
| 结局输入的默认分支误写  | 写 `flag:(2800 + 线号)` 而非 `exflag`；因所在线均无脚本可触发，暂无实际影响                                      |
| 菲娅线 `-10` 状态无出口 | 好感线崩坏（`exflag:2807 = -10`）后该线永久卡死                                                                  |

## 七、未确认事项

- 天数估算未计入据点事件与勇者入侵对节奏的干扰（都可能扣威望/资源），实测周期可能落在估算区间上沿之外。
